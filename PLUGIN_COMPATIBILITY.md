# Plugin Compatibility

The plugin compiles with Java 21 against Paper API `1.21.4-R0.1-SNAPSHOT` and declares Bukkit API version `1.20`. Maven compile and JUnit tests are verified in this repository.

Runtime compatibility with Paper, Spigot, Purpur, Fabric, or individual Minecraft versions is not claimed until the artifact is installed and exercised on that server software. Fabric requires a separate adapter. A release matrix must record server software/version, Java version, plugin version, telemetry events, heartbeat, reconnect, and shutdown results.
