Frequently Asked Questions

Got questions? We've got answers.

What is ProMcBot?
ProMcBot is a Discord bot that links Discord servers with Minecraft servers for effortless control, automation, and community management.
How do I connect my server?
Invite ProMcBot to your Discord, run the /setup_server command, and follow the prompts to authorize your Minecraft server via our plugin.
Is it free?
Yes — ProMcBot's core features are completely free. Premium plans are available for advanced features and priority support.
Which Minecraft versions are supported?
ProMcBot supports both Java Edition and Bedrock Edition servers. Our plugin is compatible with popular server softwares like Paper, Spigot, and Velocity.
Is my data secure?
Absolutely. We follow industry best practices for data security. Read our Privacy Policy for details.
