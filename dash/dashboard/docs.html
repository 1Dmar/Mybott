Getting Started

ProMcBot links your Discord server with your Minecraft server in one place. One dashboard controls everything: moderation, welcome messages, player stats, auto-responders, tickets — and a full public website for your Minecraft server.

1 Add the bot to your Discord server

Use the invite link and grant Administrator (or Manage Server) permissions so ProMcBot can protect your server and read statistics.

2 Sign in to the dashboard

Click Login, authorize with Discord, and your servers appear automatically. You only see servers where you have Administrator.

3 Connect your Minecraft server

Open Website → Minecraft Info, enter your server IP and port, and press Save. The dashboard checks the server instantly.

Inviting the Bot

Invite ProMcBot with the link below. The bot works instantly — no extra setup required.

https://promcbot.dev/loading-auth

Required permissions: Administrator (recommended) or Manage Server + Manage Messages + Embed Links.

Commands

ProMcBot uses modern slash commands. All commands work inside your Discord server.

/mc-setup

Link this Discord server with your Minecraft server. You will be asked for the IP and port — everything is saved securely to the database.

/server

Show live Minecraft server info: players online, version, MOTD, latency, and server type (Java / Bedrock / Geyser).

/lookup <player>

Look up a player that joined this server before — join history, first seen, last seen. Players that never joined are marked clearly.

Dashboard

Visit /my-servers after login. Every server card shows whether the bot is active and how many members it has. Inside each server you get: Overview, Configuration, Modules, Moderation, Roles, Logs, Auto Responder, Tickets, Welcome, MC Players, Website, and Settings.

Notifications

All events — saves, actions, warnings — arrive in the notification bell at the top right of the dashboard. You can also send custom notifications to specific members or everyone from the admin panel.

Website Builder

Create a complete public website for your Minecraft server — free. Go to your server → Website, fill the form, and press Save. Your site goes live instantly at /site/<server-id>.

Sections

General (name, tagline, banner title), Minecraft Info (Java/Bedrock IP, templates), Branding (logo, accent color), Templates, Sections (leaderboard, players list, news, Discord widget), News, Socials, Custom Domain & Subdomain, and a Live Preview.

Important: press Save

Changes are kept in the editor until you press Save. A red bar appears at the bottom saying "You have unsaved changes" — that is your button. Pressing Save publishes the site and turns the status badge to LIVE.

Public Profiles

Every user gets a public profile at /u/<discord-user-id> — avatar, banner, join date, followers and following. When a new user first enters the dashboard, they automatically follow the bot owner. You can follow or unfollow anyone anytime.

FAQ

Why do I see "Not published yet"?

It means the Website form is not saved yet. Fill in at least the site name and press Save — your website becomes live immediately.

Can I use my own domain?

Yes. Open Website → Domain and add your Custom Domain or Subdomain, then press Save.

What languages are supported?

English (default), Arabic (full RTL), and Spanish. Your choice is saved in a cookie and works on every page.

Is the bot free?

Yes — all core features, the website builder, and the public tools are free for every server owner.
