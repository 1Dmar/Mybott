Built for useful signals

Telemetry that helps you run the community.

The plugin stays focused: capture the operational signals ProMcBot needs, deliver them safely, and keep the Minecraft server responsive.

Player activity

Server intelligence

Three calm steps

Connect without guesswork.

Provision a server instance from the Dashboard, place the artifact in your server, then verify the local connection.

1
Provision credentialsOpen your server’s Plugin page in the Dashboard and create a one-time configuration.
2
Install and configurePlace the JAR in plugins and store the generated values in config.yml.
3
Verify healthRestart the server and run the local status command.
# Verify from console or in-game
/promcbot status

# Reports queue health, pending events,
# dropped events, backend state, and capabilities.
# Secrets are never printed.

Remote Minecraft command execution is not part of this release. The plugin focuses on connection, heartbeat, telemetry, and local status reporting.

Security by default

Identity belongs to your server.

One-time credentials

Provisioned access tokens and signing secrets are shown once and are never printed by the status command.

Signed requests

Requests are authenticated with the provisioned server identity and verified by the backend.

Bounded workload

Queue and retry limits keep temporary backend failures from overwhelming the Minecraft server.
