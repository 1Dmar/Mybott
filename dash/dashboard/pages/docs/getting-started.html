Invite ProMcBot Plugin guide

The path

Seven steps to a verified connection.

The Dashboard uses a server-aware flow. Only Guilds where the authenticated Discord user is the owner or has Administrator access appear in the managed-server picker.

01

Choose the server

Open /myservers and choose a server where you have Owner or Administrator access.

02

Open setup

Choose Setup & intelligence from the server sidebar.

03

Generate config

Enter an Instance ID such as primary and generate the one-time Paper config block.

04

Install the JAR

Place the ProMcBot JAR in plugins/ on a Spigot or Paper/Bukkit-compatible server, then restart it.

05

Paste the config

Paste the generated block into plugins/ProMcBot/config.yml. Never share it or commit it.

06

Check plugin status

Run /promcbot status from the console or in-game to inspect backend and queue health.

07

Wait for measurement

Refresh the Dashboard and wait for heartbeat, snapshots, or join/leave events to become Ready.

Config contract

What the generated file contains.

The one-time configuration is deliberately treated as a secret. Use the generated values only on the intended server.

# plugins/ProMcBot/config.yml
backend:
  base-url: https://your-promcbot-backend
  server-id: <provisioned server id>
  instance-id: primary
  access-token: <one-time secret>
  signing-secret: <one-time secret>

Store the generated values in Paper only. Do not put them in Discord messages, issues, repositories, screenshots, or support channels.

Troubleshooting

When the dashboard stays empty.

Empty state is part of the evidence model. Check the connection path before treating it as a UI error.

No plugin heartbeat

Confirm the base URL, server ID, instance ID, JAR placement, and the output of /promcbot status.

No player metrics

Wait for a snapshot or perform a join/leave event. IP and port do not create player telemetry.

Provisioning is unavailable

The deployment needs PLUGIN_ENCRYPTION_KEY for plugin provisioning.

Guild access required

The current Discord account is not allowed to manage that Guild, even if it can see the server.
