Compatibility

Know what is supported, and what is not verified.

The project documents compatibility honestly. Build evidence does not automatically mean every server distribution has been runtime-tested.

Platform baseline

Application and plugin support.

Use these baselines when planning a deployment.

ComponentBaselineEvidence
Node.js>=22.13.0 <23Syntax, startup, and tests verified in Node 22.
MongoDBURI through MONGO_URL or MONGO_URISchema and tests verified; live database needs credentials.
Spigot API1.8.8-R0.1-SNAPSHOTPlugin Maven package verified; Java 8 bytecode.
Spigot/Paper/Bukkit-compatible1.8.x, 1.12.x, 1.16.x, 1.20.x, 1.21.xBuild baseline or compatibility strategy; live runtime acceptance remains required per target.
PocketMine / BedrockNot a Bukkit API targetNot supported by this artifact.
Fabric / ForgeNot a Bukkit API targetNot supported by this artifact.

Production note

Build verified is not live acceptance.

Before production, exercise load, connect, heartbeat, telemetry, retry, reconnect, and shutdown on the target server distribution and Minecraft version.

The plugin does not declare a modern api-version in plugin.yml, so modern Paper may show its normal legacy compatibility warning. Record runtime acceptance per target server.
