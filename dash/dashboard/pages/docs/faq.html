Frequently asked

Keep your next step clear.

If the answer is not here, contact support with a safe, non-secret report.

Do I only need an IP and port?

No. IP and port are optional server information. Rich player data and operational telemetry require the ProMcBot Bukkit-compatible Spigot/Paper plugin.

Which server versions are supported?

The project targets Bukkit-compatible Spigot/Paper baselines and is compiled against Spigot 1.8.8 with Java 8 bytecode. Runtime acceptance should be exercised on your exact server distribution and version.

Why does the Dashboard show Not measured?

There is not enough measured telemetry for that metric yet. Wait for a snapshot or join/leave event; the product does not invent a live player count from an address.

Why is my server missing from /myservers?

The authenticated Discord user must be the Guild owner or have Administrator permission. View-only Guilds are not rendered in the managed-server picker.

How do I install the Plugin?

Generate the one-time config from Setup & intelligence, place the JAR in plugins/, restart the server, paste the config into plugins/ProMcBot/config.yml, and run /promcbot status.

Does this release execute Minecraft commands remotely?

No. Remote Minecraft command execution is not implemented in this release.
