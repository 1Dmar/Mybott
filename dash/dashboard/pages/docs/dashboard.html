Dashboard

One workspace for the servers you manage.

The Dashboard is server-aware. It keeps configuration, modules, evidence, moderation, and intelligence around the selected Guild instead of mixing unrelated server data.

Open Dashboard Follow setup

Workspace map

A focused surface for each question.

The Dashboard intentionally uses denser cards and short next steps. Every surface answers what the server is, what state it is in, and what to do next.

Managed servers

/myservers is the primary picker and shows only Guilds where the authenticated Discord user is owner or Administrator.

Access model

The selected server is not a guess.

Guild access is enforced by the backend as well as the interface. Opening a dynamic server URL without manager permission returns an access error instead of relying only on hidden UI.

View-only Guilds are not rendered in the managed-server picker, Premium selector, Intelligence setup selector, or Action Center source list.

When values are missing

The UI tells you what happened.

If heartbeat or telemetry has not arrived, the Dashboard shows explicit states such as Not connected or Not measured. It does not turn absent evidence into a number.

Not connected

The plugin instance has not supplied a current heartbeat.

Not measured

There is not enough telemetry to support a metric yet.
