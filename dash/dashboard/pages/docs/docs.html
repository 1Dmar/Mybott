Frequently asked

Answers before you begin.

If your question is not here, the support community is the fastest way to get help with a specific server setup.

What should I do first?

Invite ProMcBot, run /server setup, and complete the server connection flow. After that, use the command center to add status, moderation, and intelligence workflows.

Which permissions does the bot need?

Use the permissions requested by the Discord invite and only grant additional permissions when a module requires them. Review your server’s role settings before enabling moderation or administrative workflows.

Where do I find Minecraft player and server information?

Use the /minecraft command group for measured player activity and the /intelligence group for health, journeys, retention, reports, and actions.

How do I generate a server status image?

After your server information is configured, use /utility card. The legacy !wallp and !mc utilities are also documented in the running bot where the legacy prefix is enabled.

Does ProMcBot invent missing statistics?

The intelligence language is intentionally evidence-led. When the project does not have enough measured telemetry, the interface should show that evidence is unavailable rather than present an estimate as a fact.

Where can I get support?

Use the Support link in the navigation or join the official Discord support community. Include your server context, the command you ran, and the exact error message when reporting an issue.
