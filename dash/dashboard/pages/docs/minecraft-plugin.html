Minecraft integration

The Plugin is the bridge to real telemetry.

The current artifact is a Bukkit-compatible Spigot/Paper plugin compiled to Java 8 bytecode against the Spigot 1.8.8 API baseline.

Provision and install Compatibility

What it sends

Operational signals with a bounded queue.

The plugin records the signals the platform needs while keeping network work away from the Minecraft primary thread.

Player join and leave

Join and leave events include measured session duration where available.

Online-player snapshots

Periodic aggregate online-player counts support server and intelligence views.

Heartbeat and queue health

The backend can distinguish a live connection from delayed or offline telemetry.

Durable delivery

Events enter a bounded queue, can be written to a local spool, and use bounded timeout and retry behavior.

Install and verify

The only public Bukkit command.

After placing the JAR and configuration on the server, restart and use the local health command.

# Run from console or in-game
/promcbot status

# The output reports queue size, staged writer count,
# durable pending count, dropped events, backend state,
# and capability availability. Secrets are never printed.

Remote Minecraft command execution is not implemented in this release. The plugin is for connection, heartbeat, telemetry, and local status reporting.

Identity belongs to the server and instance.

Required values live under backend. Network ID, Minecraft server ID, and server name improve multi-server identity.
