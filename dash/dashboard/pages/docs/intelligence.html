Measured intelligence

Understand what your server actually knows.

The intelligence layer is deterministic and evidence-led. It reports measured activity, sample size, confidence, interpretation, and recommendations only when thresholds are met.

See Dashboard surfaces Read data boundaries

The model

Signals first, interpretation second.

When there is not enough data, the product says so. The current phase does not use a configured AI interpretation provider; deterministic functionality continues independently.

Server overview

Review average online players, activity trend, observed returning-player overlap, and measured session-duration trend.

Server health

See connection and telemetry health without converting stale data into a live claim.

Player journey

Understand first seen, last seen, sessions, measurable session seconds, frequency, and return behavior.

Network and reports

Use network intelligence, weekly reports, and the Actions Center when measured evidence reaches the required threshold.

What the results include

A result carries its evidence.

The intelligence APIs and UI keep context attached to the conclusion so a server team can decide whether a signal is useful.

Result detailMeaning
Sample sizeHow much measured data supports the result.
ConfidenceHow strong the evidence is for the current comparison.
Observation evidenceThe measured signals that led to the interpretation.
RecommendationShown only when a threshold is met; otherwise the UI remains explicit about insufficient data.

Player segments

Deterministic, not random.

Player intelligence can classify observed behavior into the project’s defined segments.

New

Recently observed players without enough return history.

Returning

Players with observed return behavior.

Active · Loyal · Declining · Inactive

Deterministic segments based on measured history and thresholds.
