Trust boundary

Keep credentials private and evidence honest.

Security in ProMcBot is a boundary between Discord, the Dashboard, the backend, the Plugin, and measured server data. This page explains what the repository documents without making promises beyond the implementation.

Credentials

One-time means one-time.

Generated plugin configuration contains an access token and signing secret. Treat the block as secret material.

Never share config

Do not paste generated config in Discord, issues, repositories, screenshots, or support channels.

HTTPS outside local development

The plugin base URL must use HTTPS outside local development.

Status is safe to inspect

/promcbot status reports queue and backend health without printing secrets.

Rotate after exposure

If a credential is exposed, revoke and provision a new one through the appropriate administrative flow.

Permissions and data

Access follows the managed server.

The Dashboard filters Guilds by Discord ownership or Administrator access and also enforces manager access on server APIs. The plugin sends operational telemetry required by the configured connection.

AreaBoundary
Discord managementServer configuration and manager-only views require the project’s Guild access checks.
Plugin telemetryJoin, leave, aggregate player count, heartbeat, and queue health are the documented operational signals.
Missing dataUnavailable evidence remains unavailable; the UI uses Not measured or Not connected.
SupportNever share passwords, OAuth tokens, plugin credentials, webhook URLs, API keys, private logs, or personal information.

Safe support checklist

What to include in an issue.

A useful support report is specific without exposing secrets.

Include

Server version, plugin version, command or page used, timestamp, and the exact non-secret error message.

Remove

Access tokens, signing secrets, OAuth tokens, webhook URLs, private logs, and personal information.

Verify

Check /promcbot status, base URL, server ID, instance ID, and JAR placement before escalating.
