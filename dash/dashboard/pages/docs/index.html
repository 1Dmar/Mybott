Before you ship

Use facts, not guesses.

The project intentionally keeps unavailable values explicit. A missing heartbeat is shown as not connected or not measured; it is not turned into a fabricated number.

IP and port can be saved as optional server information, but rich player data and operational telemetry require the ProMcBot Bukkit-compatible Spigot/Paper plugin.
