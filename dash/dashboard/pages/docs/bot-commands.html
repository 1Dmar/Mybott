Everyday examples

Small workflows that compound.

These are the supported paths that connect the bot, Dashboard, and plugin without inventing a live player list.

Connect

Run /server setup to start the server connection flow.

Measure

Use /minecraft players and /minecraft player for measured activity.

Protect

Start with /moderation settings, then configure filters, actions, allowlists, and logs.

Share

Use /utility card for a server status image or /utility playercard for a player card.

Legacy utilities

Prefix commands are secondary.

Where the legacy prefix is enabled, the existing !mc and !wallp utilities remain available. Slash commands are the canonical interface for new setup and configuration flows.

Do not use legacy names as a replacement for the grouped slash commands. If a command is not present in the canonical catalog, it is not part of the public Docs surface.
