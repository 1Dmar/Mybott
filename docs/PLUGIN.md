# Minecraft Plugin

The current ProMcBot artifact is a **Bukkit-compatible Spigot/Paper plugin compiled to Java 8 bytecode** against the Spigot API `1.8.8-R0.1-SNAPSHOT` baseline. It establishes server and instance identity from `config.yml`, receives a provisioned access token and signing secret, signs telemetry requests with HMAC-SHA256, and performs network work asynchronously so backend communication does not block the Minecraft primary thread.

The plugin records operational signals required by the platform: player join, player leave with measured session duration, periodic aggregate online-player count, and heartbeat/queue health. Events receive stable IDs, enter a bounded in-memory queue immediately, and are handed to a dedicated `TelemetrySpoolWriter` that performs durable base64/tab append and `fsync` away from the Minecraft primary thread. Recovery runs at startup, and a flush waits for accepted spool writes before successful backend delivery can acknowledge and remove records. Batches use bounded timeouts and exponential retry. Gameplay remains usable when telemetry or the internet is offline; events may remain pending or be dropped after the configured durable bound with an explicit status signal.

The only public Bukkit command is `/promcbot status`. It reports queue size, staged writer count, durable pending count, dropped event count, backend online/offline state, and capability availability. It never prints the access token or signing secret. The permission is `promcbot.status`, defaulting to true because the output is local health information rather than credential material.

Required configuration is under `backend`: `base-url`, `server-id`, `instance-id`, `access-token`, and `signing-secret`. `network-id`, `minecraft-server-id`, and `server-name` improve multi-server identity. The base URL must use HTTPS outside local development. Durable spool configuration is bounded and local; generated config contains empty placeholders and no production secrets.

Maven `clean test package` succeeds and the generated JAR contains `plugin.yml`, the plugin main class, `BackendClient`, `TelemetryEvent`, `TelemetryQueue`, `TelemetrySpool`, and `TelemetrySpoolWriter`. Live installation acceptance still requires a real Spigot/Paper server, valid provisioned credentials, a reachable backend, and observation that heartbeat and telemetry appear in the Dashboard. Spigot/Paper/Bukkit-compatible runtime support for each target version remains **IMPLEMENTED BUT UNVERIFIED** until exercised on that server. PocketMine-MP/Bedrock, Fabric, and Forge are not supported by this artifact. Remote Minecraft command execution is not implemented in this release.
